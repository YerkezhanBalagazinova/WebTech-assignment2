# Web Technologies — Assignment 2

This is my second assignment for Web Technologies. The main goal of this assignment was to practice Flexbox and CSS Grid and understand how they can be used for different page layouts.

## What I made

The assignment includes several small webpages:

- **Flexbox page** — I created a navigation bar and three cards about beautiful places in Kazakhstan. I used Flexbox to arrange the elements and added a hover effect to the cards.

- **AITU page** — I created a simple page about Astana IT University. I used CSS Grid to divide the page into a header, sidebar, main content, and footer.

- **Cat Gallery** — I created a gallery with nine cat memes using CSS Grid. The images are arranged in three rows and three columns, and captions appear when the images are hovered.

- **Portfolio page** — In the final task, I combined Flexbox and Grid. The page contains my previous projects and a small About Me section.
